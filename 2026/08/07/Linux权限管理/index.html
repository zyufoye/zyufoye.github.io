Linux权限管理

发表于 2026-08-07 分类于 软考 阅读次数：

文件权限

rwx421读写执行

文件所有者-文件所属组用户-其他用户

- 普通文件
d 目录文件
l 链接文件
b 设备文件
p 管道文件

drwxr-xr-x 2 root root 4.0K May 10 22:31 Desktop

第一个root代表所属用户，第二个root代表所属组；

去除文件的执行权限命令：

chmod a-x openvpn

chmod ugo-x openvpn

chmod 644 openvpn

为所有用户添加可执行权限：

chmod +x file

chmod a+x file

chmod ugo+x file

chmod -R 用于递归修改权限。-R, —recursive 表示“递归地更改文件和目录”。

Linux系统安全增强

最小化系统网络服务：

inetd.conf 的文件权限设置为 600；

inetd.conf 的文件属主为 root；

services 的文件权限设置为 644；

services 的文件属主为 root。

限制远程访问：

/etc/hosts.allow 和 /etc/hosts.deny 允许和禁止远程主机对本地服务的访问。

白名单的安全性会更高一些；

vim /etc/hosts.allow

允许内容 书写格式
ssh 允许单个 IP sshd:192.168.220.1
ssh 允许 IP 段 sshd:192.168.220.
telnet 允许单个 IP in.telnetd:192.168.220.1
telnet 允许 IP 段 in.telnetd:192.168.221.

用户超时注销：TMOUT=600 所有用户在10分钟无操作后自动注销；

访问控制策略

两个网络安全模型：BLP模型和Biba模型。

BLP：Bell-LaPadula BLP机密性模型，防止非授权信息访问扩展。

  • 简单安全特性：不能向上读，只能向下读；
  • *特性：只能向上写，不能向下写；

机密性模型，不能保证完整性，因为可以向上写会破坏完整性。

Biba模型：防止非授权篡改，保证信息系统完整性。

  • 简单安全特性：不能向下读；
  • *特性：不能向上写；
  • 调用特性：不能向上调；

访问控制三要素：主体、客体、（访问控制数据库、参考监视器、审计库）；

Linux密码管理

超级用户 root UID=0

系统密码文件： /etc/passwd 对所有用户可读（644）；

root:x:0:0:root:/root:/bin/bash

用户名：加密口令占位：用户ID：组ID：用户全名或描述：登录目录：登录shell

第二列是用户的口令或密码，若为x则表示密码存储到了/etc/shadow中

/etc/shadow 只有root能读 （400）存储密码详细信息

用户名：用户加密后的口令（若为空则不需口令即可登录，若为*则表示用户禁用）
