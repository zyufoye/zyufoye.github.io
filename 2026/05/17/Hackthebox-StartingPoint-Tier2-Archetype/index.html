第二层级是“StartingPoint”中的最高层级，包含功能齐全的机器，需要用户串联多个攻击步骤才能成功入侵。用户必须进行彻底的枚举，获取初始立足点，然后逐步提升权限至 root 或系统级别。与之前的层级不同，第二层级中的每台机器都包含两个标志——一个用于用户，一个用于 root/系统——这模拟了真实的渗透测试场景，需要更全面的方法。

知识点

扩展存储过程 (Extended Stored Procedure): 在数据库里，”存储过程”就是一段提前写好的 SQL 代码。而”扩展存储过程”允许 MSSQL 数据库调用外部的动态链接库（DLL），这意味着数据库可以直接与底层的 Windows 操作系统进行交互。

在现代的 MSSQL 版本（2005 之后）中，出于安全考虑，微软默认禁用了 xp_cmdshell。
