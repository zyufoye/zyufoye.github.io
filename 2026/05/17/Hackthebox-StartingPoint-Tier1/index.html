9.语言 php

在这个特定的靶机场景中，S3 存储桶实际上被用作了该网站（thetoppers.htb）的后端存储目录（即 Web 根目录）。

  • 文件同步/挂载：这台服务器在内部进行了配置，使得托管网站文件的目录（比如 /var/www/html）与名为 thetoppers.htb 的 S3 存储桶进行了绑定或同步。我们在 S3 存储桶里看到的 index.php，正是网站首页运行的代码。
  • 漏洞产生的核心原因：正是因为这种直接的绑定关系，当攻击者（你）使用 AWS 命令行工具（aws cli）将包含恶意代码的 shell.php 上传到这个 S3 存储桶后，这个文件就直接出现在了网站的目录中。
  • 实现攻击：当你通过浏览器访问 http://thetoppers.htb/shell.php 时，网站服务器不仅能找到你刚刚上传的文件，而且服务器配置了 PHP 环境，它会解析并执行这个木马脚本，从而导致你的机器获得了目标服务器的控制权（反向 Shell）。

简而言之，它们的关系是：S3 存储桶 = 网站所在的文件夹。控制了存储桶，就等于获得了随意篡改、添加网站代码的权限。
