网站安全

文档详细讲解了网站安全需求分析与安全保护工程，从理论分析到具体软件（Apache、IIS）的加固，再到Web应用漏洞及综合防护方案，形成了一个完整的网站安全建设框架。

一、 网站安全威胁与需求分析

网站是基于B/S技术架构的综合信息服务平台，提供网页信息和业务后台对外接口服务。

  • 网站安全核心属性：机密性（防泄露）、完整性（防篡改）、可用性（防中断）、可控性（防滥用）。
  • 主要安全威胁：
    1. 非授权访问：撞库、口令猜测。
    2. 网页篡改与恶意代码：植入网页木马，控制终端。
    3. 数据泄露：敏感信息被窃取。
    4. 网站假冒：域名欺骗、劫持、中间人攻击（钓鱼网站）。
    5. 拒绝服务（DoS/DDoS）：如UDP、ICMP、SYN、HTTP Flood。
    6. 后台管理威胁：管理员密码被窃、权限分配不当。

网站安全需求涉及多个方面：物理环境、网络通信、操作系统、数据库、应用服务器、Web服务/应用、数据库安全等。

二、 Apache Web 安全分析与增强

Apache httpd 是一个搭建Web服务器的开源软件。配置文件如下：

  • httpd.conf 主配置文件
  • conf/srm.conf 数据配置文件
  • conf/access.conf 基本读取文件控制/f访问控制
  • conf/mime.conf 设定能识别的MIME格式

常见威胁：软件程序漏洞（缓冲区溢出）、配置不当（目录索引泄露）、认证机制薄弱、通信未加密、全连接耗尽攻击等。

Apache Web 主要面临以下以下安全威胁：软件程序、软件配置威胁，安全机制威胁，应用程序威胁，服务通信、服务内容‘拒绝服务威胁。

Apache Web 安全机制：本地文件安全，认证机制，模块管理，连接耗尽应对机制。

应对连接耗尽攻击，Apache 可以：
（1）减少超时设置，减少 Timeout，增大 Maxclients；
（2）限制同一IP最大连接数；
（3）多线程下载保护机制；
（4）自带访问控制，审计与日志（access.log error.log）,防DDoS；

安全增强与加固方案：

1.  **打补丁**：及时更新Apache软件。
2.  **权限控制**：遵循最小特权原则，为Apache分配专门的用户和组（不使用预定义的nobody）。 
3.  **信息隐藏**：隐藏Apache软件版本号（修改`ServerSignature`和`ServerTokens`）。
4.  **目录保护**：禁止显示动态目录索引（`-Indexes`），禁止默认访问，启用`.htaccess`保护网页。.htaccess配置文件保护，设置网页密码，重定向文件，禁止读取文件名等。
5.  **抗DoS攻击**：减少超时设置（Timeout）、限制同一IP连接数、使用防多线程下载机制或第三方防DoS模块。
6.  **环境隔离**：构建“安全沙箱”（chroot机制），限制软件运行范围。
7.  **通信加密**：配置Open SSL实现HTTPS加密传输。

三、 IIS Web 安全分析与增强

  • 常见威胁：非授权访问、网络蠕虫（利用缓冲区溢出）、CVE软件漏洞（XSS、代码执行等）、拒绝服务。
  • IIS内置安全机制：
    • 认证：匿名、基本验证、证书认证、数字签名、Windows NTLM认证。
    • 访问控制流程：IP地址限制检查 -> 用户身份验证 -> Web权限检查 -> NTFS文件许可权限检查。
  • 安全增强方案：及时安装IIS补丁、启用动态IP限制（防暴力破解和DoS）、启用URLScan过滤危险请求、部署IIS WAF（Web应用防火墙）、启用SSL服务。

四、 Web应用漏洞分析与防护 (基于OWASP Top 10)

  • 两类漏洞：技术安全漏洞（SQL注入、XSS等）与业务逻辑漏洞（如密码找回缺陷、短信炸弹）。
  • 常见漏洞及防护：
    1. SQL注入漏洞：
      • 防护：对输入进行安全过滤（建立黑白名单）、设置数据库最小化权限（避免使用DBA权限连接）、屏蔽应用程序报错信息回显，对开源 Web应用做安全适应性改造。
    2. 文件上传漏洞：
      • 防护：将上传目录设置为不可执行，严格检查上传文件安全性。
    3. 跨站脚本攻击 (XSS)：
      • 攻击模式包括HTML内容替换、嵌入脚本代码等（需对输入输出做转义和验证）。
    4. 其他OWASP高危漏洞：受破坏的认证、敏感数据暴露、XXE（外部实体注入）、失效的访问控制、安全配置错误、不安全的反序列化、使用带已知漏洞的组件、日志监控不足。

五、 网站安全保护机制与技术方案

构建网站整体安全的综合保护体系，包含以下技术机制：

  1. 身份鉴别与访问控制：用户名/口令、U盾、生物识别；防火墙拦截。
  2. 数据与内容安全：网页防篡改（文件底层监控或密码学哈希校验）、敏感词过滤、数据隔离与SSL加密。
  3. 攻击防护与流量清洗：部署WAF拦截Webshell、SQL注入等；部署抗DDoS清洗设备。
  4. 安全监测与扫描：定期漏洞扫描、网页挂马监测、合规性与备案监测、性能与DNS监测。
  5. 审计与应急响应：SysLog收集、网络/数据库审计；建立灾备中心、制定应急预案并开展等级保护测评。

六、 网站安全综合应用案例 (政务网站)

  • 合规要求：政府网站信息安全等级原则上不低于二级（二级每两年测评，三级每年测评一次）。
  • 整体架构方案部署：
    • 网络边界：防DDoS系统 + 防火墙（访问控制）。
    • 应用层：Web应用防火墙 (WAF) 清洗异常流量 + IPS/防病毒网关检测阻断。
    • 服务器端：防篡改监控代理（保护文件）。
    • 后端支撑：网络/数据库审计系统（监控后台数据操作）。
    • 管理面：网站安全监控系统。
