数据库安全

文档记录了数据库系统安全，涵盖了安全概况、实现机制以及针对主流数据库（Oracle、MS SQL、MySQL、国产数据库）的安全分析与防护策略。

一、 数据库安全核心概念与目标

  • 安全核心：保障数据库的机密性、完整性、可用性。
  • 四大领域：涉及数据库管理安全、数据安全、数据库应用安全以及数据库运行安全。
  • 终极目标：保护数据库系统的安全运行及数据资源的安全性。

二、 面临的安全威胁与隐患

数据库环境日益开放，主要面临以下严重威胁和内部隐患：

  1. 授权的误用：合法用户越权获得他们不应该获得的资源，或将自身的访问特权不适当地授予其他用户。
  2. 逻辑推断和汇聚：利用逻辑推理，把不太敏感的数据结合起来可以推断出敏感信息。
  3. 伪装：假冒合法身份。
  4. 旁路控制：在数据库设置后门，绕过访问控制。
  5. 隐蔽信道：利用非正常的通信途径传输数据以躲避数据库安全机制的控制。
  6. SQL注入攻击：应用程序的输入未进行安全检查。
  7. 口令破解：利用黑客手段进行“撞库”。
  8. 硬件及介质攻击。
  9. 系统与配置隐患：缺少强制密码机制、有公开的默认账号和默认密码；扩展存储过程成为数据库系统的后门；系统软件与应用程序漏洞；权限分配隐患；以及网络通信内容未经加密导致明文传递。

三、 关键安全机制与实现技术

为了满足标识鉴别、访问控制、审计、加密等8大安全需求，主要采用以下技术：

  1. 数据库加密：
    • 传输层：网上传输的数据通常利用SSL协议。
    • 存储层：通过数据库存储加密（分为库内加密和库外加密）。具体技术可细分为将数据库文件作为整体加密、对每一个记录加密，或深入到加密数据库的字段。
  2. 数据库防火墙（主动防御）：
    • 核心逻辑：根据预定义的禁止和许可策略让合法的SQL操作通过，阻断非法违规操作。提供SQL注入禁止和数据库虚拟补丁包功能。
    • 关键作用：
      • 屏蔽直接访问数据库的通道（部署在服务器和应用之间）。
      • 增强认证（必须经过防火墙和数据库两层身份认证）。
      • 攻击检测（检测SQL注入和缓冲区溢出，并报警或者阻止攻击行为）。
      • 防止漏洞利用（实现虚拟化补丁）。
      • 防止内部高危操作（限定更新和删除影响行、限定无Where的更新和删除操作、限定drop、truncate等高危操作）。
      • 防止敏感数据泄露与数据库安全审计。
  3. 数据库脱敏：
    • 利用脱敏技术变换处理数据，在保持数据按需使用目标的同时，又能避免敏感数据外泄（采取屏蔽、变形、替换、随机、加密等手段）。
  4. 数据库漏洞扫描：
    • 对目标数据库的安全性尝试进行安全探测分析，收集数据库漏洞的详细信息。

四、 主流数据库安全防护与最佳实践

  • Oracle 数据库：
    • 机制：支持操作系统认证、网络认证、多级认证、SSL认证等（采用“用户名+口令”）。需进行特别认证和第三方/PKI/远程认证。
    • 特色功能：建立保险库 (DV)保护敏感数据（防未授权变更、多因素授权等），通过安全域和命令规则特权控制，可阻止未授权命令操作。支持细粒度安全审计和高级安全功能（透明数据加密和数据屏蔽）。
    • 最佳实践：增强操作系统安全、最小化安装、安装补丁、删改默认口令、设置最小化权限、限制IP地址、启用传输加密及Oracle审计、实施灾备计划。
  • MS SQL 数据库：
    • 机制：支持Windows认证和混合认证。采用基于角色的访问控制（固定服务器、固定数据库、应用角色）。提供透明数据加密（涉及服务主密钥、数据库主密钥、数据库密钥）。支持静态备份和动态备份的多种方案。
    • 最佳实践：加强扩展存储过程管理，删除不必要的存储过程；确保网上数据加密传输；修改默认TCP/IP端口号；进行IP限制和日志审计；及时修补漏洞。
  • MySQL 数据库：
    • 机制：支持用户身份认证、灵活的访问授权（通过 grant 和 revoke 命令）及安全审计。
    • 最佳实践：建立单独启动的用户和组；建立 Chrooting 运行环境（沙箱）；关闭远程连接（关3306端口）；禁止导入本地文件；修改root用户ID、密码和用户名；删除默认用户和db；建立独立使用数据库和用户账号；进行安全监测和安全备份。
  • 国产数据库：
    • 概况：由国家自主研发力量研制，遵循《信息安全技术数据库管理系统安全技术要求》。
    • 安全威胁：除了自身漏洞和第三方组件影响外，主要威胁来自系统安全配置不当（如未启用国产数据库安全功能、设置数据库弱口令、开放过多的服务端口、使用非安全远程登录工具）。
    • 防护措施：安全漏洞挖掘及扫描、加密、使用安全数据库。
