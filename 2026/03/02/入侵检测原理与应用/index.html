入侵检测原理与应用

发表于 2026-03-02 更新于 2026-08-22 分类于 软考 阅读次数：

入侵检测系统IDS

模块一：入侵检测的基础概念与定位

1. 什么是入侵检测（IDS）？

  • 概念：入侵是指违背了目标安全策略的行为。IDS 通过收集操作系统、网络包等信息，来发现这些违规行为。
  • 判断依据：对目标的操作是否超出了目标的安全策略范围。
  • 角色定位：如果说防火墙是“门卫”，那么 IDS 就是网络中的预警机或巡逻员。它的直接目的不是阻断（那是IPS或防火墙干的事），而是发现、记录和报警，为应急响应和取证提供依据。

2. CIDF 通用模型（四大组件）
现代 IDS 都遵循 CIDF 框架，包含四个部分：

  • 事件产生器：负责到处收集数据（抓包、拿日志）。
  • 事件分析器：大脑，负责分析数据是否异常。
  • 响应单元：依据分析结果做出反应（如发警报）。
  • 事件数据库：存储数据和结果。

模块二：两大核心检测技术流派（重点）

这是 IDS 最核心的理论，分为“误用检测”和“异常检测”两大流派，外加一些新型辅助技术。

1. 基于误用的检测（又称：基于特征的检测）

  • 原理（对号入座）：建立一个已知攻击的特征模式库（黑名单）。如果抓到的数据和库里的特征匹配上了，就认定是入侵。
  • 优缺点：优点是准确率高，一抓一个准（比如 Snort 规则）；缺点是高度依赖特征库的更新，对于库里没有的新型攻击（未知攻击）毫无办法。
  • 具体方法：状态迁移、条件概率、规则匹配、键盘监控等。

2. 基于异常的检测

  • 原理（寻找异类）：先给系统或用户的正常行为画一个“轮廓”（建立正常基线/白名单）。如果当前行为严重偏离了这个正常基线，就认为是异常/入侵。
  • 优缺点：优点是能发现未知的、新型的攻击；缺点是误报率极高（因为“异常”不一定等于“入侵”，比如管理员偶尔半夜登录也会被当成攻击）。
  • 具体方法：统计分析、模式预测、文本分类、贝叶斯推理等。

3. 其他新型检测技术

  • 沙箱动态分析：把可疑文件放进一个隔离的“安全屋（沙箱）”里运行，看它有没有搞破坏的动作（专治隐藏极深的木马）。
  • 报警关联分析：把海量零碎的报警连起来看，消除噪音，挖出背后复杂的连环攻击。
  • 攻击诱骗：故意弄个假系统（蜜罐）吸引黑客攻击，从而反向追踪黑客。

根据数据来源和部署位置，IDS 分为三大类：

1. 基于主机的 IDS（HIDS）

  • 数据源：主机的系统日志、CPU/内存状态、注册表、文件完整性等。
  • 部署：直接以软件形式安装在被保护的服务器上。
  • 优缺点：优点是不怕网络加密（因为数据到了主机已经解密了），能防范内部人员操作；缺点是耗费服务器性能，且一旦服务器被黑，HIDS 本身也可能被破坏。无法看到整个网络的宏观扫描。 HIDS包含软件： SWATCH 监视软件、Tripwire 文件和目录完整性检测工具、网页防篡改。

2. 基于网络的 IDS（NIDS）

  • 数据源：网络上流动的通信数据包。
  • 部署：作为一个旁路设备，接在交换机的镜像端口上（静静地旁听）。
  • 优缺点：优点是不影响现有网络性能，对黑客隐蔽，能监控一大片网络；缺点是遇到高加密流量就成了“瞎子”，且在高速网络下容易“漏抓”（漏包）。

3. 分布式 IDS（DIDS）

  • 原理：面对大型复杂网络，采用“多点探测、集中管理”的模式。把 HIDS 和 NIDS 结合起来，统一把情报汇总到一个管理中心进行综合分析。

模块四：演进产品与实际部署

1. 产品的演进
除了传统的 HIDS 和 NIDS，目前衍生出了更多形态：

  • UTM（统一威胁管理）：把防火墙、IDS、杀毒等功能集成在一个铁盒子（硬件）里。
  • APT 检查：专门针对潜伏深、利用文档（PDF/Word）传播的高级持续性威胁。
  • 细分领域 IDS：专盯网页攻击的 Web IDS、专盯数据库违规操作的 数据库 IDS、专盯工业设备的 工控 IDS。
  • IDS相关指标：可靠、可用、时效、准确、安全、可扩展。

2. 部署规范与方法

  • 7 步部署法：确定保护对象 -> 装探测器 -> 定策略 -> 选架构 -> 配规则 -> 测试验证 -> 运行维护。
  • 经典部署位置：
    • 测内网威胁：把 NIDS 挂在内网核心交换机的镜像端口上，查内鬼。
    • 测边界威胁：把 NIDS 挂在防火墙后面的网络边界处，查外部黑客。

💡 核心总结

学习 IDS，只需记住一句话：它是网络里的“监控摄像头”和“警报器”。它通过认黑名单（误用特征）或找行为反常（异常基线）来发现坏人。在部署上，装在电脑里的叫 HIDS，趴在交换机上偷听的叫 NIDS。
