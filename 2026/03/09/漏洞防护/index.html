一、网络安全漏洞概述

核心概念

网络安全漏洞（脆弱性）：致使网络信息系统安全策略相冲突的缺陷，通常称为安全隐患。

漏洞影响范围

机密性受损 / 完整性破坏 / 可用性降低 / 抗抵赖性缺失 / 可控制性下降 / 真实性不保

漏洞分类（按补丁状况）⭐

类型 说明
普通漏洞 漏洞信息已广泛公开，安全厂商已有修补方案
零日漏洞（Zero-day） 新发现、尚未提供补丁的漏洞，通常用于定向攻击

漏洞威胁类型

网络信息系统漏洞的存在是攻击成功的必要条件之一。

敏感信息泄露 / 未授权访问 / 身份假冒 / 拒绝服务

我国漏洞相关平台与标准 ⭐

  • CNNVD：国家信息安全漏洞库（中国信息安全测评中心建设）
  • CNVD：国家信息安全漏洞共享平台（国家计算机网络应急技术处理协调中心）
  • 相关标准：GB/T 33561 / GB/T 30279 / GB/T 28458 / GB/T 30276

二、网络安全漏洞分类与管理

漏洞来源分类

非技术性安全漏洞（5类）

类型 说明
安全责任主体不明确 缺少负责安全的机构
安全策略不完备 缺少规范的安全策略
操作技能不足 缺少安全培训机制
安全监督缺失 缺少强有力的监督机制
特权控制不完备 超级用户权限缺少审计和约束

技术性安全漏洞（8类）⭐

类型 说明
设计错误 系统或程序设计错误导致
输入验证错误 未验证用户输入合法性
缓冲区溢出 输入数据超过缓冲区规定长度，破坏堆栈
意外情况处置错误 未考虑意外情况导致运行出错
访问验证错误 逻辑错误使攻击者绕过访问控制
配置错误 配置参数、权限、策略配置有误
竞争条件 时序和同步问题造成的短暂可利用时机
环境错误 环境变量错误或被恶意设置

漏洞分类标准 ⭐

1. CVE（美国MITRE公司）

  • 安全漏洞统一标识字典，目标是便于共享漏洞数据
  • CVE ID 格式：年份数字 + 其他数字，如 CVE-2019-1543
  • 条目内容：标识数字 + 漏洞简要描述 + 至少一个公开参考

2. CVSS（通用漏洞计分系统）⭐

评分由三部分组成：

计分维度 关键参数
基本度量计分 攻击向量、攻击复杂性、特权要求、用户交互、完整性/保密性/可用性影响、影响范围
时序度量计分 漏洞利用代码成熟度、修补级别、漏洞报告可信度
环境度量计分 完整性/保密性/可用性要求、修订基本得分

3. 我国漏洞分类 ⭐

CNNVD 漏洞分类（25类，重点记）：

配置错误、代码问题、资源管理错误、数字错误、信息泄露、竞争条件、输入验证、缓冲区错误、格式化字符串、跨站脚本、路径遍历、后置链接、SQL注入、代码注入、命令注入、操作系统命令注入、安全特征问题、授权问题、信任管理、加密问题、未充分验证数据可靠性、跨站请求伪造、权限许可和访问控制、访问控制错误、资料不足

CNVD 漏洞分类（11类）：

输入验证错误、访问验证错误、意外情况处理错误、边界条件错误、配置错误、竞争条件、环境错误、设计错误、缓冲区错误、其他错误、未知错误

CNVD 危害级别：高 / 中 / 低 三级

4. OWASP TOP 10（Web应用漏洞）⭐

注入、失效的身份认证、敏感信息泄露、XML外部实体(XXE)、失效的访问控制、安全配置错误、跨站脚本(XSS)、不安全的反序列化、使用含已知漏洞的组件、不足的日志记录和监控、未验证的重定向和转发、非安全加密存储

漏洞管理过程（5个环节）⭐

环节 核心内容
资产确认 摸底调查，建立信息资产档案
漏洞信息采集 收集漏洞类型、补丁级别、影响资产
漏洞评估 评估业务影响、被利用可能性、修补级别，形成威胁排序
漏洞消除和控制 安装补丁包、升级系统、更新IPS/IDS特征库、变更管理流程
漏洞变化跟踪 持续跟踪漏洞状态，持续修补

三、网络安全漏洞扫描技术

漏洞扫描器组成（4模块）

漏洞扫描器三种类型 ⭐

类型 特点 局限
主机漏洞扫描器 检查本地关键文件内容及安全属性，无需网络连接，只能单机检测 仅限本地
网络漏洞扫描器 建立网络连接，发送特定请求，便于远程检查 无本地权限，检查能力受限
专用漏洞扫描器 针对特定系统（数据库/网络设备/Web/工控） 范围专一

四、网络安全漏洞处置技术

漏洞发现技术

漏洞发现方法依赖于人工安全性分析、工具自动化检测及人工智能辅助分析。把已发现的漏洞进行总结，形成一个特征库，利用特征库进行智能化识别。

文本搜索、词法分析、范围检查、状态机检查、错误注入、模糊测试、动态污点分析、形式化验证

补丁管理六环节 ⭐

漏洞利用防范技术（5种）⭐

针对漏洞利用触发条件进行干扰和拦截。

技术 原理
地址空间随机化（ASLR） 对程序加载内存地址随机化，使攻击者无法预知返回地址，防御缓冲区溢出
数据执行阻止（DEP） 将特定内存区域标注为非执行，保护堆栈区域
SEHOP 防止攻击者利用结构化异常处理（SEH）重写
堆栈保护 设置堆栈完整性标记，检测函数调用返回地址是否被篡改
虚拟补丁 不修改程序，通过过滤网络流量中的漏洞攻击数据包保护目标系统，由IPS/WAF实现

五、主要产品与技术指标

漏洞扫描器技术指标 ⭐

指标 说明
扫描主机数量 有无IP/域名限制
并发数 支持并发扫描任务数量
扫描速度 单位时间扫描效率
漏洞检测能力 数量、类型、是否覆盖主流OS/数据库/网络设备
数据库漏洞检查 Oracle/MySQL/MS SQL/DB2/Sybase/PostgreSQL/MongoDB
Web应用漏洞检查 SQL注入/XSS/网站挂马/网页木马/CGI漏洞
口令检查功能 SMB/Telnet/FTP/SSH/POP3/SQL Server/MySQL/Oracle等口令猜测
标准兼容性 兼容CVE/CNNVD/CNVD/BugTraq，提供CVE兼容证书
部署环境 是否支持虚拟化VM平台

漏洞防护网关技术指标

常见产品：IPS、WAF（Web防火墙）、UTM（统一威胁管理）

指标 说明
阻断攻击种类与数量 能防御的漏洞利用类型及数量
阻断准确率 检测并阻止漏洞利用的正确程度
阻断性能 单位时间内有效阻止的数量
支持网络带宽能力 对网络流量大小的控制能力

📌 高频考点速记

  1. 零日漏洞 = 无补丁 + 定向攻击
  2. CVE ID格式：年份+数字，如 CVE-2019-1543
  3. CVSS三维度：基本度量 / 时序度量 / 环境度量
  4. CNVD危害级别：高 / 中 / 低
  5. 漏洞管理5步：资产确认→采集→评估→消除控制→变化跟踪
  6. 漏洞消除方法：打补丁 / 升级系统 / 更新IPS特征库 / 变更管理流程
  7. ASLR 防缓冲区溢出；DEP 防内存区域执行；虚拟补丁 靠流量过滤
  8. 补丁管理6环节：现状分析→跟踪→验证→安装→应急→检查
  9. 漏洞防护网关产品：IPS / WAF / UTM
