Java单元测试

发表于 2026-01-27 分类于 Java 阅读次数：

Java 的单元测试（Unit Test）是独立运行的，只需要通过构建工具（Maven）来触发它们，而不需要先把整个项目运行起来。

可以把“测试”想象成是给代码做体检，不需要从头到尾全部检查一遍，只需要对某个器官（类或方法）进行单独检查。
