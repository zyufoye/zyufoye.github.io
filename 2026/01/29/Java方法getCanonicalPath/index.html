总结

特性 说明
主要用途 获取文件的唯一、规范化绝对路径
核心功能 解析 .、..、符号链接
安全作用 防止路径遍历攻击
性能 较慢（涉及系统调用），建议缓存
异常 抛出 IOException
现代替代 Path.toRealPath() (Java 7+)

安全关键点：在处理用户提供的文件路径时，必须使用 getCanonicalPath() 或 toRealPath() 进行边界检查！
